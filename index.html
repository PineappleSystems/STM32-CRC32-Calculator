• Case insensitive (both uppercase and lowercase HEX allowed)

📋 Algorithm Info

  • CRC32 IEEE 802.3 (standard)
  • Polynomial: 0x04C11DB7 (0xEDB88320 reversed)
  • Initial value: 0xFFFFFFFF
  • Final XOR: 0xFFFFFFFF
  • Reflection: Input & Output reflected
  • Compatible with STM32 hardware CRC

🔧 Usage Example

  • Input: 0x01, 0x02, 0x03, 0x04
  • CRC32: 0xB63CFBCD
  • Verify with STM32 CRC unit
  • Matches standard tools like WinRAR, PNG

⚙️ Technical Notes

  • Little-endian byte order
  • 32-bit result (unsigned integer)
  • Online calculator for embedded systems
  • No data sent to server (client-side only)
